How to use SocialMedia Manager

Our own app for planning, approving, publishing and measuring posts on Instagram, Facebook and the LinkedIn company page. It runs on this laptop. This guide grows with every step that changes what you can do.

Where we are: the app can connect the Facebook Page and Instagram and test the whole route to them without publishing (Test send). Writing, approving and automatic posting come next, ready by 6 December 2026. Until the first real post (Fri 4 Dec) and the pilot pass, keep posting with Meta Business Suite and LinkedIn's own scheduler.

What you will see

  • Open the app with the SocialMedia Manager shortcut on your desktop. It starts in about 2 seconds and opens in your browser at http://127.0.0.1:8090.
  • When you have not used it for 30 minutes, the app stops by itself so it does not slow the laptop. Just use the shortcut again. (If a page says it cannot connect, the app has stopped: use the shortcut.)
  • There is no login screen: on this laptop you are signed in automatically as the owner. Other devices, even on your Wi-Fi, are refused.
  • The top bar shows the Moggies International mark and name, and a bell for messages from the app (for example "account access expires soon").

Starting and updating

  • Normally you do nothing except open the app from the desktop shortcut when you want it. Its daily jobs (account check and backup) run by themselves at 09:00, or as soon as the laptop is on after that (no window).
  • To install approved changes: double-click Update and start.bat in the App folder. It shows the changes waiting, asks Install them now? (Y/N), then restarts the app and opens it. If nothing is waiting it says Already up to date and just opens the app.
  • If it says Your App folder has changes, nothing was changed; send the message to Claude.

Brands

Everything in the app belongs to a brand: its connected accounts, posts and numbers. Moggies International is the first, and the app opens straight into it.

  • Add another business: open the brand menu at the top left and choose Add a brand. Type its name (for example Moggies Export Services) and save. Names must be different.
  • Change a brand's name or time zone: brand menu → Brand settings. The time zone is used for post times and reports; India (Asia/Kolkata) is the default.

Connected accounts

The Connected accounts page (left menu) lists the brand's Facebook Page, Instagram account and LinkedIn company page with their state. Facebook and Instagram are connected from the Meta page (below); LinkedIn comes once LinkedIn approves our access.

If the laptop has no internet at that moment, nothing changes. Disconnect makes the app forget its access to that account; posts already published stay online. The access is stored encrypted and is never shown on screen.

Meta (Facebook & Instagram): the permanent key

The app reaches the Facebook Page Moggies International and Instagram @moggies_international with a permanent key made in Meta's business settings for the system user Moggies SMM App. It does not expire, so there is no reconnecting every few months. Each copy of the app (App and Dev) has its own key.

  1. App Secret (once): on developers.facebook.com open Moggies Social Manager → App settings → Basic → App Secret → Show. In the app open Meta (Facebook & Instagram) → Save App Secret and paste it there.
  2. Access (once): business.facebook.com/settings → System users → Moggies SMM App → Assigned assets. The Page Moggies International: Full control (Meta lets only admin-level access upload Facebook videos). The app Moggies Social Manager: Full control. Instagram moggies_international: Content, Community activity and Insights, with Messages off.
  3. Make the key: business.facebook.com/settings, portfolio Moggies Social Manager → Users → System users → Moggies SMM App → Generate token. Choose the app Moggies Social Manager, expiry Never, and tick only: pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_engagement, pages_read_user_content, read_insights, instagram_basic, instagram_content_publish, instagram_manage_insights, instagram_manage_comments, business_management. Nothing for ads or messages.
  4. Save it: copy the key and press Save Meta key on the Meta page. The app checks it with Meta and connects the Page and Instagram by itself. The page then shows "works, never expires" and both accounts.
Keep it secret: the App Secret and the key can post as the business. Paste them only into the app, never into a chat, email or document. The app stores them locked and shows only "Saved on <date>". If one might have leaked, make a new key (and you can remove the old one in business settings).

The page warns when the key is missing a permission the app needs (it then does not connect), lacks permissions needed later for statistics and comments, or has more access than needed. Check the key now asks Meta again.

Hostinger folder

Instagram only takes photos and videos from a web address, and this laptop has none. Just before an Instagram post the app puts the file in a hidden folder on moggiesinternational.com and deletes it straight after. The folder can't be listed or found by search engines, and its FTP account can reach nothing else on the website. Don't put other files in it.

  • Setting it up (once, with Claude, about 10 minutes): in hPanel → Files → FTP Accounts, make an account whose folder is the hidden folder Claude names. In the app open Hostinger folder → Folder details and type the server, user, password and the folder's public address. The password is stored locked and never shown; leave it empty later to keep it.
  • Test the folder checks everything in about 10 seconds: the lock file, upload, download from the website, that the folder can't be listed, delete, and that the file is gone. Each step shows ✓ or ✗ with a plain note.

Test send

Test send (left menu) takes one photo (.jpg) and one video (.mp4 or .mov) from your Markting Social Media folder through every step to Instagram and Facebook and stops just before publishing: nothing is published.

  • Instagram: the file goes to the Hostinger folder, Instagram downloads and prepares it, then the file is removed.
  • Facebook: the file is uploaded unpublished, checked, then deleted.
  • It takes 1 to 3 minutes; keep the page open. The result lists every step with ✓ or ✗. Your files in Markting Social Media are only read, never changed.
  • It works in both copies, because nothing becomes public. Real posts go out only from App.

Backups

  1. First time: open Backups (left menu) → Set backup password. Use at least 12 characters and type it twice. Write it down and keep it away from the laptop: without it nobody can open the backups, not even Claude.
  2. Every day (when the laptop is on) the app saves a locked copy of everything into the Backups folder by itself. The newest 14 are kept. You can also press Back up now.
  3. About once a week: plug in your USB drive, copy the whole D:\Pravin\Moggi\SocialMedia_Manager\Backups folder onto it, then press I copied Backups to my USB drive today. The app reminds you after 7 days.
  4. To restore: ask Claude. (By hand, a backup opens with the free 7-Zip and your password.)

The dashboard's Backups card turns into a list of warnings when something needs you: no password yet, a failed backup, no backup for over a day, or the USB copy is due.

Check that the app is healthy

Open PowerShell in the App folder and run:

cd D:\Pravin\Moggi\SocialMedia_Manager\App
php artisan smm:doctor

Every line should start with OK. On your App copy the last line reads Publish mode: live. A line starting with FAIL says what is wrong and how to fix it; send it to Claude if it is not clear.

For Claude: the Windows task and the shortcut

Installed from the App copy (one administrator prompt for the owner): the desktop shortcut (start.ps1 -Open) and the task \SocialMediaManager\Daily (daily 09:00, start when available, S4U, 1-hour limit, never wakes the laptop). It also removes the older Server and Tick tasks.

powershell -ExecutionPolicy Bypass -File .\scripts\windows\install-tasks.ps1

Other scripts in scripts\windows: start.ps1 [-Open], stop.ps1, daily.ps1 (one run of the daily jobs), serve.ps1 (runs php artisan smm:serve, which stops after 30 minutes without use). Logs are in the data folder's logs folder.

For Claude: Meta and Hostinger commands

  • php artisan smm:meta:rehearse --photo="<full path .jpg>" --video="<full path .mp4>": the Test send from the command line; exit code 1 when a step fails. Never publishes, in any copy.
  • php artisan smm:meta:test-post (App only; Dev refuses): one public Facebook text post with a reference code, to check while signed out that app posts are public. Delete it within 10 minutes with --delete; the daily jobs delete a leftover one. Only with the owner's OK.
  • scripts\windows\wake-trial.ps1 [-Sleep]: what Windows allows without an administrator prompt for waking the laptop at post times; results in the data folder's run\wake-trial.json and in docs\superpowers\plans\2026-11-19-sm-008-decisions.md. -Sleep puts the laptop to sleep: only with the owner present.
  • The folder's lock file is scripts\hostinger\relay.htaccess; Test the folder writes it into the folder.
  • Dev never publishes: every Meta call that would publish is refused before it is sent unless the copy is App with SMM_PUBLISH_MODE=live.

For Claude: setting up a copy

Only needed once per copy, or on a new laptop after the code is downloaded from GitHub (the script installs the packages itself). It never replaces an existing app key.

powershell -ExecutionPolicy Bypass -File .\scripts\windows\setup.ps1 -DataDir D:\Pravin\Moggi\SocialMedia_Manager\Data -PublishMode live -BackupDir D:\Pravin\Moggi\SocialMedia_Manager\Backups

The tools it needs are PHP 8.5 (installed with winget) and Composer (D:\Tools\ComposerSetup). If a PHP upgrade ever resets PHP's settings, smm:doctor reports the missing extensions.
