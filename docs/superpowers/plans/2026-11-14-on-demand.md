# SM-007 On-demand running Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (owner chose native execution). Steps use `- [ ]`.

**Goal:** The app uses the laptop only while it is used or needed: it starts from a desktop shortcut, stops itself after 30 minutes without use, and its jobs run once a day instead of every minute.

**Architecture:** `php artisan smm:serve` runs PHP's server as a child process and stops it when the data folder's `run/last-activity` file is older than the idle limit; a middleware touches that file on every request except `/up`. `php artisan smm:daily` runs the account check, the backup (if older than 20 hours) and records the heartbeat; one Windows task runs it daily at 09:00 (or as soon as the laptop is on after a missed 09:00). The Server and Tick tasks are removed.

**Spec:** the owner's decision of 14 Nov 2026 (chat): "run only when needed or while using" — proposal accepted: desktop shortcut, 30-minute idle stop, daily jobs at 09:00, exact-time wake-ups for posts later (plan 2). Amends `docs/PROJECT_PLAN.html` §8 and tracker #16.

## Global Constraints
- Windows PowerShell 5.1 scripts, plain ASCII; PHP via Start-Process redirection (no native stderr redirection).
- Idle limit 30 minutes (`config('smm.idle_minutes')`); daily jobs considered late after 26 hours (`config('smm.heartbeat_stale_minutes') = 1560`).
- Daily task: S4U, daily 09:00, StartWhenAvailable, never WakeToRun, 1-hour limit. No Server or Tick task remains after install.
- No background polling from open pages (database-notification polling off), so an idle tab lets the server stop.

## Review Focus
1. `/up` (used by start.ps1 to detect the app) must not count as use, or the app never stops (Task 1 test).
2. A missed 09:00 (laptop off) must still run the account check and backup later: `smm:daily` runs them directly, not through `schedule:run` minute matching (Task 2 test).
3. `smm:daily` must keep going when the backup cannot run (no password) and still record the heartbeat (Task 2 test).
4. Exactly 30 minutes idle stops; 29 does not (Task 1 test).
5. Re-running install must remove the old Server/Tick tasks (Task 3 verification).
